# 01-plan

Put `plan.json` here: the single source of the sport's plan (objective, findings, architecture, scope, roadmap, requirements with acceptance criteria, RAID log, controls, glossary). `../PLAN.md` is rendered from it.

Copy `NFL/01-plan/render_plan_md.py` and change its title line. The shape of `plan.json` is the one in `NFL/CONTRACTS.md` §10; `NFL/01-plan/plan.json` is a worked example.
